# AGENTS.md — Agent Notes

Agent Note 是 agent 写的决策记录：持久的取舍、被放弃的替代方案、代价与验证。写之前先读 [规则](README.md)，它的格式由 `test/notes.test.ts` 机械检查（头部、`Status:` 与目录一致、必填小节、相对链接可解析）。

**每写一篇新笔记都要做一次取代检查。** 搜一遍活跃目录里有没有覆盖同一决定的旧笔记；完全被取代的 `implemented/` 笔记并在当前笔记里后删除，部分取代的两篇互相链接。`archived/` 若建立起来，里面的文件是冻结的历史快照：不要编辑，也不要当作当前权威。
